# Famora R6.5 — Security & Concurrency Regression Test Plan

**Status:** **`NOT_RUN`** (Requires isolated local Supabase / PostgreSQL with Docker + `psql`; never run against production).

---

## 1. Concurrency & Race Condition Tests (Isolated PostgreSQL)

1. **`redeem_family_reward` Double-Spend Test (F-01):**
   - Setup: Member A has `100` points in `reward_points_ledger`; Reward R costs `100` points.
   - Execution: Launch two concurrent sessions calling `SELECT public.redeem_family_reward(family_id, reward_id)`.
   - Expected: Exactly **1** succeeds (`true`), **1** fails with `Not enough points to redeem this reward` (`22023`), and `SUM(delta_points) = 0` (never `-100`).

2. **`cast_poll_vote` Concurrent Single-Choice Vote Test (F-04):**
   - Setup: Poll P (`allow_multiple = false`, `allow_vote_edit = false`) with options `opt_1`, `opt_2`.
   - Execution: Launch two concurrent sessions for Member A voting `[opt_1]` and `[opt_2]`.
   - Expected: Exactly **1** succeeds, **1** fails with `Vote editing is disabled for this poll` (`42501`), and `COUNT(*) = 1` in `family_poll_votes`.

3. **`record_finance_transaction` Opposing-Transfer Deadlock & Idempotency Test (F-03):**
   - Execution: Run concurrent `A -> B` and `B -> A` transfers, plus two concurrent calls with the same `p_idempotency_key`.
   - Expected: Zero `40P01` deadlocks; duplicate `p_idempotency_key` returns the same `tx_id` and updates account balances **once**.

## 2. Authorization & Financial Integrity Tests

4. **Transfer to Another Member's Personal Account (F-03):**
   - Setup: Member A (`finance.transactions.manage`) transfers from Family Account -> Member B's `personal` account.
   - Expected: Rejected with `42501` (`Not authorized to access destination personal account`).

5. **Reverse Another Member's Personal Transaction (F-02):**
   - Setup: Member A (`finance.transactions.manage`) calls `reverse_finance_transaction` on Member B's `personal` account transaction.
   - Expected: Rejected with `42501`.

6. **Archived Account Transaction Rejection (F-03):**
   - Setup: Archive Account A (`is_archived = true`), then call `record_finance_transaction`.
   - Expected: Rejected with `22023` (`Source account is archived`).

7. **Debt Overpayment / Settled Debt Rejection (F-05):**
   - Setup: Debt D has `remaining_numeric = 50.00`.
   - Execution: Call `record_debt_payment(..., 60.00)` -> expect `22023`; call `record_debt_payment(..., 50.00)` -> expect `true` (`status = 'settled'`); call `record_debt_payment(..., 10.00)` again -> expect `22023`.

8. **`is_chat_participant` `search_path` Hardening (F-06):**
   - Verify `proconfig` contains `search_path=public, famora, pg_temp`.
